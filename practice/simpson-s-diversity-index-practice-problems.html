Simpson's diversity index practice problems

Biology Unit 8. Try each one, then open the worked solution. The Credit Sprint app generates unlimited new versions with fresh numbers.

Problem 1.

A sample has 8 oaks, 5 maples and 7 pines. Using D = 1 − Σ(n/N)², what is Simpson's diversity index? (Round to 2 decimals.)

Show solution

N = 20. Σ(n/N)² = (8/20)² + (5/20)² + (7/20)² = 0.345. D = 1 − 0.345 = 0.66.
