Credit Sprint's Guide to AP® Calculus AB and BC, Unit 5: Analytical Applications of Differentiation

AB weight 15–20%BC weight 10–15%CLEP® about 16%

Unit 5 uses derivatives to analyze the shape of a function: the Mean Value Theorem, the Extreme Value Theorem, increasing and decreasing intervals, relative and absolute extrema, concavity, points of inflection, and optimization. It also asks you to connect the graphs of f, f′ and f″.

What you need to know

  • Mean Value Theorem: if f is continuous on [a, b] and differentiable on (a, b), then f′(c) = [f(b) − f(a)] ÷ (b − a) for some c in (a, b). Some tangent line is parallel to the secant line. State both conditions.
  • Extreme Value Theorem: a function continuous on a closed interval [a, b] has an absolute maximum and an absolute minimum on that interval.
  • A critical point is an x in the domain where f′(x) = 0 or f′(x) does not exist. Relative extrema can only happen at critical points.
  • f is increasing where f′ > 0 and decreasing where f′ < 0. Make a sign chart for f′ using the critical points.
  • First derivative test: if f′ changes from + to − at c, f has a relative maximum at c; from − to +, a relative minimum. No sign change, no extremum.
  • Candidates test (closed interval method): to find absolute extrema on [a, b], evaluate f at every critical point inside the interval and at both endpoints. The biggest value is the absolute maximum; the smallest is the absolute minimum.
  • f is concave up where f′ is increasing (f″ > 0) and concave down where f′ is decreasing (f″ < 0). A point of inflection is where concavity changes, which is where f″ changes sign (or f′ changes from increasing to decreasing).
  • Second derivative test: if f′(c) = 0 and f″(c) > 0, relative minimum; if f″(c) < 0, relative maximum; if f″(c) = 0, the test is inconclusive.
  • Reading graphs: zeros of f′ (where the f′ graph crosses the axis) are candidates for extrema of f; peaks and valleys of f′ are points of inflection of f; where f′ is above the axis, f rises.
  • Optimization: write the quantity to maximize or minimize as a function of one variable, find its domain, find critical points, and justify the answer with the first derivative test, second derivative test or candidates test.
  • A justification must name the derivative and its sign. 'f has a relative minimum at x = 2 because f′ changes from negative to positive there' earns the point; 'because the graph goes down then up' does not.

Formulas

  • MVT: f′(c) = [f(b) − f(a)] / (b − a)
  • Critical point: f′(c) = 0 or undefined
  • f″ > 0 ⇒ concave up; f″ < 0 ⇒ concave down
  • Second derivative test: f′(c) = 0 and f″(c) > 0 ⇒ rel. min

Exam traps

Watch forf″(c) = 0 does not guarantee an inflection point. f(x) = x⁴ has f″(0) = 0 but is concave up on both sides.
Watch forf′(c) = 0 does not guarantee an extremum. f(x) = x³ has f′(0) = 0 but keeps increasing.
Watch forFor an absolute extremum on a closed interval, check the endpoints too. Many exam answers hide there.
Watch forWhen you are given the graph of f′, not f, read the sign of f′ for increasing/decreasing and the slope of f′ for concavity. Do not read the f′ graph as if it were f.
Watch forThe MVT needs continuity on the closed interval and differentiability on the open interval. A function with a corner can fail it.

Key terms

  • Mean Value Theorem: If f is continuous on [a, b] and differentiable on (a, b), then f′(c) = [f(b) − f(a)]/(b − a) for some c in (a, b).
  • Rolle's Theorem: The MVT with f(a) = f(b): then f′(c) = 0 for some c in (a, b).
  • Extreme Value Theorem: A function continuous on [a, b] has an absolute maximum and minimum on [a, b].
  • Critical point: An x in the domain where f′(x) = 0 or f′(x) does not exist.
  • Increasing: f′ > 0 on the interval.
  • Decreasing: f′ < 0 on the interval.
  • First derivative test: f′ changes + to −: relative maximum. − to +: relative minimum.
  • Candidates test: For absolute extrema on [a, b], evaluate f at the critical points and endpoints; compare.
  • Concave up: f′ increasing (f″ > 0); the graph lies above its tangent lines.
  • Concave down: f′ decreasing (f″ < 0); the graph lies below its tangent lines.
  • Point of inflection: A point where the concavity changes (f″ changes sign).
  • Second derivative test: f′(c) = 0 and f″(c) > 0: rel. min. f″(c) < 0: rel. max. f″(c) = 0: inconclusive.
  • Reading an f′ graph: f′ above the axis: f increasing. f′ rising: f concave up. Zeros of f′ where it crosses: extrema of f.
  • Optimization: Write the quantity in one variable, find its domain, find critical points, justify the max or min.
  • Justification language: Name the derivative and its sign: 'because f′ changes from negative to positive at x = 2'.

Practice questions

Five of the 73 Unit 5 questions in Credit Sprint. Every choice is explained in the app.

1. The graph of f′ crosses the x-axis from above to below at x = 4. What happens to f at x = 4?
  1. f has a horizontal asymptote
  2. f has a point of inflection
  3. f has a relative maximum
  4. f has a relative minimum
Show answer

f has a relative maximum. f′ changes from positive to negative, so f switches from increasing to decreasing: a relative maximum.

2. For f(x) = x⁴, f″(0) = 0. Does f have a point of inflection at x = 0?
  1. Yes, because f″(0) = 0
  2. Yes, because f′(0) = 0
  3. It cannot be determined
  4. No, because f″ does not change sign at 0
Show answer

No, because f″ does not change sign at 0. f″(x) = 12x² is positive on both sides of 0, so the graph stays concave up.

3. f is differentiable and has a relative maximum at x = c. What is f′(c)?
  1. 0
  2. Negative
  3. Positive
  4. It does not exist
Show answer

0. At an interior relative extremum of a differentiable function, the tangent line is horizontal.

4. At what value of x does f(x) = x³ + 6x² + 9x have a relative maximum?
  1. x = 0
  2. x = −3
  3. x = −1
  4. x = −2
Show answer

x = −3. f′(x) = 3(x − (−3))(x − (−1)) after factoring. f′ changes from + to − at x = −3 (relative maximum) and from − to + at x = −1 (relative minimum). So the answer is x = −3.

5. For f(x) = −2x² + 8x on [−2, 1], what value of c satisfies the conclusion of the Mean Value Theorem?
  1. c = −1/2
  2. c = 2
  3. c = −2
  4. c = 10
Show answer

c = −1/2. The secant slope is [f(1) − f(−2)] ÷ 3 = 10. Set f′(c) = −4x + 8 equal to it and solve: c = −1/2. (For any quadratic, c is the midpoint.)
