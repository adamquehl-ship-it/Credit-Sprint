Credit Sprint's Guide to AP® Precalculus, Unit 2: Exponential and Logarithmic Functions

AP® weight 27–40%CLEP® about 25%

Unit 2 moves from adding to multiplying. Arithmetic sequences and linear functions change by a constant difference; geometric sequences and exponential functions change by a constant ratio. You build exponential models, use logarithms as their inverses, solve equations with the properties of logs, and test models with semi-log plots and residuals.

What you need to know

  • An arithmetic sequence adds a common difference d: aₙ = a₀ + dn. A geometric sequence multiplies by a common ratio r: gₙ = g₀rⁿ. They are the discrete versions of linear and exponential functions.
  • Linear functions change by equal amounts over equal input intervals; exponential functions change by equal factors over equal input intervals.
  • An exponential function f(x) = a·bˣ has initial value a and base (growth factor) b > 0, b ≠ 1. If b > 1 it grows; if 0 < b < 1 it decays. The graph has a horizontal asymptote, y = 0 before any vertical shift.
  • A growth rate of r% per period gives b = 1 + r/100; a decay rate gives b = 1 − r/100. Equivalent forms rescale the input: doubling every T years means f(t) = a·2^(t/T) = a·(2^(1/T))ᵗ.
  • Properties of exponents: bᵐbⁿ = bᵐ⁺ⁿ, (bᵐ)ⁿ = bᵐⁿ and b⁻ⁿ = 1/bⁿ. A horizontal shift of an exponential is the same as a vertical dilation: b^(x + k) = bᵏ·bˣ.
  • Compound interest: A = P(1 + r/n)ⁿᵗ. Continuous growth: A = Pe^(rt), where e ≈ 2.718.
  • A logarithm is an exponent: log_b(c) = a means bᵃ = c. log_b x and bˣ are inverse functions, so their graphs reflect over y = x. ln x means log base e.
  • Logarithmic functions are defined only for positive inputs, have a vertical asymptote at x = 0 (before shifts), increase without bound, and grow more slowly than any power function.
  • Properties of logs: log_b(MN) = log_b M + log_b N; log_b(M/N) = log_b M − log_b N; log_b(Mᵏ) = k·log_b M; change of base: log_b x = ln x ÷ ln b.
  • Solve exponential equations by rewriting with a common base or by taking a log of both sides. Solve log equations by rewriting in exponential form. Always check log equations for extraneous solutions.
  • Semi-log plots: if y = a·bˣ then ln y = ln a + (ln b)x, which is linear in x. Data that look straight on a semi-log plot are exponential.
  • Judge a model with its residuals (actual − predicted). Random scatter around 0 means the model fits; a pattern means a different function type may be better.
  • The inverse of a function swaps inputs and outputs. To find it, swap x and y and solve for y. A function must be one-to-one to have an inverse function; you may restrict its domain to make it one.

Formulas

  • aₙ = a₀ + dn and gₙ = g₀rⁿ
  • f(x) = a·bˣ; percent change: b = 1 ± r
  • A = P(1 + r/n)ⁿᵗ and A = Pe^(rt)
  • log_b c = a ⇔ bᵃ = c
  • log_b(MN) = log_b M + log_b N, log_b(M/N) = log_b M − log_b N, log_b Mᵏ = k log_b M
  • Change of base: log_b x = ln x ÷ ln b

Exam traps

Watch forlog(M + N) is not log M + log N. There is no rule for the log of a sum.
Watch forA 6% growth rate means b = 1.06, not 0.06 or 6.
Watch forAn exponential with a negative base is not allowed. The base must be positive and not 1.
Watch forThe domain of ln(x − 4) is x > 4, not x ≥ 4: ln 0 is undefined.
Watch forHalf-life questions use (1/2) raised to the number of half-lives, not the number of days.

Key terms

  • Arithmetic sequence: aₙ = a₀ + dn: add the common difference d each step.
  • Geometric sequence: gₙ = g₀rⁿ: multiply by the common ratio r each step.
  • Exponential function: f(x) = a·bˣ with a ≠ 0, b > 0 and b ≠ 1.
  • Growth factor: The base b; b > 1 is growth, 0 < b < 1 is decay.
  • Percent growth rate r: Growth factor b = 1 + r; for decay, b = 1 − r.
  • Exponential horizontal asymptote: y = a·bˣ + k approaches y = k at one end.
  • e: An irrational constant ≈ 2.718, the base of continuous growth and of ln.
  • Continuous growth: A = Pe^(rt).
  • Compound interest: A = P(1 + r/n)ⁿᵗ.
  • Half-life: The time for a quantity to halve: A = A₀(1/2)^(t/h).
  • Doubling time: The time for a quantity to double: A = A₀·2^(t/T).
  • Logarithm: log_b c = a means bᵃ = c: the exponent that turns b into c.
  • Natural logarithm: ln x = log base e of x.
  • Common logarithm: log x = log base 10 of x.
  • Product rule for logs: log_b(MN) = log_b M + log_b N.
  • Quotient rule for logs: log_b(M/N) = log_b M − log_b N.

Practice questions

Five of the 119 Unit 2 questions in Credit Sprint. Every choice is explained in the app.

1. Which table of values is best modeled by an exponential function?
  1. x: 0, 1, 2, 3 and y: 5, 15, 45, 135
  2. x: 0, 1, 2, 3 and y: 5, 6, 9, 14
  3. x: 0, 1, 2, 3 and y: 5, 10, 15, 20
  4. x: 0, 1, 2, 3 and y: 5, 4, 5, 4
Show answer

x: 0, 1, 2, 3 and y: 5, 15, 45, 135. Each output is 3 times the one before: a constant ratio is the sign of an exponential model.

2. Which property is correct for b > 0, b ≠ 1, and positive M and N?
  1. log_b(M + N) = log_b M · log_b N
  2. log_b(MN) = log_b M + log_b N
  3. log_b(Mᵏ) = (log_b M)ᵏ
  4. log_b(M/N) = log_b M ÷ log_b N
Show answer

log_b(MN) = log_b M + log_b N. Exponents add when powers multiply, so logs of products add.

3. A function f has constant output ratios over equal-length input intervals. Then f is…
  1. quadratic
  2. exponential
  3. linear
  4. logarithmic
Show answer

exponential. Equal multiplication over equal steps is the defining property of exponential functions.

4. An arithmetic sequence has a₂ = 7 and common difference −2. What is a₁₇?
  1. 1
  2. −23
  3. −27
  4. −21
Show answer

−23. aₙ = aₖ + (n − k)d = 7 + 15(−2) = −23.

5. A geometric sequence has g₀ = 2 and common ratio 2. What is g₅?
  1. 1024
  2. 64
  3. 12
  4. 32
Show answer

64. gₙ = g₀·rⁿ = 2·(2)⁵ = 64.
