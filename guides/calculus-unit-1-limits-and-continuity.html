Credit Sprint's Guide to AP® Calculus AB and BC, Unit 1: Limits and Continuity

AB weight 10–15%BC weight 5–10%CLEP® about 10%

Calculus begins with the limit: the value a function approaches as the input gets close to a number. You estimate limits from graphs and tables, compute them with algebra, use the squeeze theorem, and use limits to define continuity, asymptotes and end behavior. Every later idea, the derivative and the integral included, is a limit.

What you need to know

  • The limit of f(x) as x approaches c is the value f(x) gets close to as x gets close to c from both sides. It does not depend on f(c), or on whether f(c) even exists.
  • A two-sided limit exists only if the left-hand limit and the right-hand limit exist and are equal. Jumps make one-sided limits disagree; vertical asymptotes make them unbounded; wild oscillation (like sin(1/x) near 0) means no limit.
  • Estimate limits from a graph (follow the curve, not the dot) or from a table (look at values from both sides). Tables suggest a limit but never prove one.
  • Direct substitution works for polynomials, rational functions where the denominator is not zero, and every continuous function. If you get a number, that is the limit.
  • If substitution gives 0/0, the form is indeterminate: factor and cancel, rationalize with a conjugate, combine fractions, or use a known limit. Then substitute again.
  • Two limits to know: lim(x→0) sin x / x = 1 and lim(x→0) (1 − cos x)/x = 0. Use them to evaluate trigonometric limits such as lim sin(5x)/x = 5.
  • The squeeze theorem: if g(x) ≤ f(x) ≤ h(x) near c and g and h both approach L, then f approaches L too. It is the classic way to show lim x²·sin(1/x) = 0.
  • A function is continuous at x = c when f(c) is defined, the limit as x → c exists, and the two are equal. Polynomials, exponentials, sine and cosine are continuous everywhere; rational, log and root functions are continuous on their domains.
  • Discontinuities come in three types: removable (a hole: the limit exists but does not equal f(c)), jump (one-sided limits differ) and infinite (a vertical asymptote).
  • Limits at infinity describe end behavior and horizontal asymptotes. For a rational function compare degrees: bigger bottom → 0; equal degrees → ratio of leading coefficients; bigger top → no horizontal asymptote. Exponentials grow faster than any power, and powers faster than logarithms.
  • A vertical asymptote at x = c means f(x) → ±∞ as x → c from at least one side. Check the sign on each side to decide between +∞ and −∞.
  • The Intermediate Value Theorem: if f is continuous on [a, b] and N is between f(a) and f(b), then f(c) = N for at least one c in (a, b). On the exam, always state that f is continuous on the closed interval.

Formulas

  • lim(x→0) sin x / x = 1
  • lim(x→0) (1 − cos x) / x = 0
  • Continuity at c: lim(x→c) f(x) = f(c)
  • IVT: f continuous on [a, b] and N between f(a) and f(b) ⇒ f(c) = N for some c in (a, b)

Exam traps

Watch forThe limit at c is about nearby values, not f(c). A hole at x = 2 with a dot at a different height still has a limit equal to the hole's height.
Watch for0/0 is not 'undefined, so no limit'. It is indeterminate: simplify first, then substitute.
Watch forA nonzero number over 0 (like 3/0) signals a vertical asymptote: the limit is +∞, −∞ or does not exist, depending on the signs from each side.
Watch forDo not use the IVT without saying the function is continuous on the closed interval. That is the point that earns the credit.
Watch forFor horizontal asymptotes of functions with √(x²) in them, remember √(x²) = |x|, so x → −∞ can give a different asymptote from x → +∞.

Key terms

  • Limit: The value f(x) approaches as x approaches c from both sides; it does not depend on f(c).
  • One-sided limit: The value f(x) approaches as x approaches c from only the left (x → c⁻) or only the right (x → c⁺).
  • When a two-sided limit exists: When the left-hand and right-hand limits both exist and are equal.
  • Indeterminate form 0/0: A form that gives no answer by itself; simplify by factoring, rationalizing or L'Hospital's Rule.
  • lim(x→0) sin x / x: 1.
  • lim(x→0) (1 − cos x) / x: 0.
  • Squeeze theorem: If g ≤ f ≤ h near c and g and h both approach L, then f approaches L.
  • Continuity at x = c: f(c) is defined, lim(x→c) f(x) exists, and the two are equal.
  • Removable discontinuity: A hole: the limit exists but f(c) is missing or does not equal it.
  • Jump discontinuity: The one-sided limits exist but are different.
  • Infinite discontinuity: A vertical asymptote: f(x) → ±∞ as x → c from at least one side.
  • Vertical asymptote: A line x = c where f(x) grows without bound as x approaches c.
  • Horizontal asymptote: A line y = L with f(x) → L as x → ∞ or x → −∞.
  • End behavior of a rational function: Bigger bottom degree: y = 0. Equal degrees: ratio of leading coefficients. Bigger top degree: no horizontal asymptote.
  • Intermediate Value Theorem: If f is continuous on [a, b] and N is between f(a) and f(b), then f(c) = N for some c in (a, b).
  • Growth rates: As x → ∞: logarithms grow slower than powers, and powers slower than exponentials.

Practice questions

Five of the 71 Unit 1 questions in Credit Sprint. Every choice is explained in the app.

1. The graph of f has a hole at (2, 5), and f(2) = 1. What is lim(x→2) f(x)?
  1. 1
  2. Does not exist
  3. 3
  4. 5
Show answer

5. The limit depends on the values of f near x = 2, which approach the height of the hole, 5. The value f(2) does not matter.

2. Which limit equals 1?
  1. lim(x→0) (1 − cos x) ÷ x
  2. lim(x→0) x ÷ sin(2x)
  3. lim(x→0) sin(x) ÷ x
  4. lim(x→∞) sin(x) ÷ x
Show answer

lim(x→0) sin(x) ÷ x. This is the standard trigonometric limit, which equals 1.

3. f is continuous everywhere, f(0) = 2 and f(3) = 2. Which must be true?
  1. f has no zeros
  2. Nothing about f(c) = 0 can be guaranteed
  3. f(c) = 0 for some c in (0, 3)
  4. f is constant on [0, 3]
Show answer

Nothing about f(c) = 0 can be guaranteed. The IVT only guarantees values between f(0) and f(3). Both are 2, so it guarantees nothing else, and f may never be 0.

4. What is lim(x→2) (x² − x − 2) ÷ (x² − 4)?
  1. 0
  2. 1/2
  3. 3/4
  4. The limit does not exist
Show answer

3/4. Both parts are 0 at x = 2, so factor: (x − 2) cancels, leaving (x + 1) ÷ (x + 2). Substitute: 3 ÷ 4 = 3/4.

5. What is lim(x→∞) (9x² + 3x + 2) ÷ (7x² + 5x + 3)?
  1. 0
  2. 9/7
  3. 2/3
  4. ∞
Show answer

9/7. The degrees are equal (2), so the limit is the ratio of leading coefficients: 9 ÷ 7 = 9/7.
